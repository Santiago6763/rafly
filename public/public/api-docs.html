API Documentation

Integrá sorteos criptográficamente seguros en tu app, bot o plataforma con la API de RAFLY.

Base URL: https://rafly.onrender.com/api/v1

Autenticación

Todas las requests a la API requieren un API key. Pasalo como header X-API-Key o como query param api_key.

# Header (recomendado)
curl -H "X-API-Key: rfly_abc123..." \
  https://rafly.onrender.com/api/v1/account

# Query param
curl https://rafly.onrender.com/api/v1/account?api_key=rfly_abc123...

Podés crear hasta 5 API keys desde esta misma página (abajo) o desde tu dashboard.

Sortear ganador(es)

POST /api/v1/sorteo/random

Selecciona ganador(es) aleatorios de una lista usando criptografía segura (crypto.randomInt).

Request Body

CampoTipoDescripción
participantsstring[]*Lista de nombres (máx 10,000)
countintegerCantidad de ganadores (default: 1)
removeDuplicatesbooleanEliminar duplicados (default: false)

Ejemplo

curl -X POST https://rafly.onrender.com/api/v1/sorteo/random \
  -H "X-API-Key: rfly_abc123..." \
  -H "Content-Type: application/json" \
  -d '{
  "participants": ["Ana", "Pedro", "Luis", "Maria", "Carlos"],
  "count": 2,
  "removeDuplicates": true
}'

Respuesta

{
  "winners": ["Maria", "Luis"],
  "total_participants": 5,
  "draw_time": "2026-09-11T15:30:00.000Z",
  "method": "crypto.randomInt"
}

Historial de sorteos

GET /api/v1/sorteos

Lista el historial de sorteos realizados con tu cuenta.

Query Params

CampoTipoDescripción
limitintegerCantidad (default: 20, máx: 100)
offsetintegerOffset para paginación (default: 0)

Ejemplo

curl https://rafly.onrender.com/api/v1/sorteos?limit=5 \
  -H "X-API-Key: rfly_abc123..."

Info de cuenta

GET /api/v1/account

Devuelve info de tu cuenta y límites del plan.

Ejemplo

curl https://rafly.onrender.com/api/v1/account \
  -H "X-API-Key: rfly_abc123..."

Respuesta

{
  "email": "user@example.com",
  "plan": "pro",
  "api_limits": {
    "daily": 1000,
    "perMinute": 60
  }
}

Ejemplos

JavaScript / Node.js

const res = await fetch('https://rafly.onrender.com/api/v1/sorteo/random', {
  method: 'POST',
  headers: {
    'X-API-Key': 'rfly_tu_key_aqui',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    participants: ['Ana', 'Pedro', 'Luis'],
    count: 1
  })
});
const { winners } = await res.json();
console.log(`Ganador: ${winners[0]}`);

Python

import requests

resp = requests.post(
    "https://rafly.onrender.com/api/v1/sorteo/random",
    headers={"X-API-Key": "rfly_tu_key_aqui"},
    json={
        "participants": ["Ana", "Pedro", "Luis"],
        "count": 1
    }
)
data = resp.json()
print(f"Ganador: {data['winners'][0]}")
